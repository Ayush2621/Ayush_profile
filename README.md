# Ayush Raj — Portfolio

Cinematic, responsive developer portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Requirements
- Node.js 20+ recommended
- npm

## Local development
```bash
npm ci
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deploy to Vercel
Import the GitHub repository into Vercel. Framework preset: **Vite**; build command: `npm run build`; output directory: `dist`.

## SEO setup
The project includes title/description metadata, canonical URL, Open Graph and Twitter metadata, Person structured data, `robots.txt`, `sitemap.xml`, and Vercel asset caching headers. If the production domain changes, update the canonical, Open Graph, JSON-LD, and sitemap URLs in `index.html` and `public/sitemap.xml` / `public/robots.txt`. After deployment, verify the domain in Google Search Console and submit the sitemap. Search indexing is controlled by search engines and cannot be guaranteed.

## Certificates
The certificate names are based on the supplied résumé. Add official certificate URLs or scanned certificate images when available; links are intentionally not invented.

## Image quality
The site uses responsive web assets and CSS scaling. “4K” describes display resolution, not a guarantee of native 4K source imagery; use high-resolution originals for project artwork when available.
